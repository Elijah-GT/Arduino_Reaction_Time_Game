# Arduino_Reaction_Time_Game
Two Player Arduino reaction time game. When the RED light turns off and the buzzer sounds, click your button as quickly as possible.
Components: Arduino Uno
            Two white LEDS, one red LED, one yellow LED, one green LED
            Five 220Ohm resistors
            One active buzzer
            Two buttons
